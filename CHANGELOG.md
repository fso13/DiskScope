## [1.0.0] - 2026-10-20

### Добавлено

- Нативное приложение DiskScope для macOS 14+: анализ диска, тепловая карта,
  крупнейшие файлы и приложения, распределение по типам.
- Быстрый сканер на `getattrlistbulk` + `openat` с запасным путём
  `readdir + fstatat`, прогрессом и отменой.
- Компактное дерево скана: плоские массивы узлов и общий UTF-8-блоб имён;
  файлы меньше 64 КБ агрегируются по папкам.
- Двухуровневая squarified-карта с навигацией по папкам, подсказками и
  полосой с именем родителя.
- Очистка: «Показать в Finder» и «Переместить в Корзину» с подтверждением.
  После удаления дерево и суммы обновляются без полного перескана
  (copy-on-write).
- Учёт пакетов `.app`, симлинков и точек монтирования.
- Русский интерфейс, светлая и тёмная темы, клавиатурные сокращения.
- Полностью локальная работа: без сети, телеметрии и внешних зависимостей.
- 23 XCTest: точность против `du`, агрегация, пакеты, Unicode-имена, отказ
  доступа, отмена, удаление, раскладка карты и полный цикл `AppModel`.
- `diskscope-cli` для замеров и `DiskScopeSnapshots` для PNG-рендера интерфейса.
- GitHub Actions: сборка релиза по тегу и публикация документации на
  GitHub Pages.
- Кнопка «Скачать последний релиз» на сайте документации и постоянная ссылка
  на universal-архив `DiskScope-macos-universal.zip`.
- Сайт документации оформлен в стиле личного сайта: Dracula-палитра,
  JetBrains Sans/Mono, тёмный hero с терминалом, карточки и галерея.

### Ограничения

- Жёсткие ссылки считаются по каждому пути, а не один раз.
- Снимки APFS и purgeable-пространство не показываются отдельно.
- Файлы меньше 64 КБ не показываются по отдельности.
- Поиска дубликатов нет.
