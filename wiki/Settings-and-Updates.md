# Настройки и обновления

Открыть настройки можно тремя способами:

- `⌘,`;
- шестерёнка в правом верхнем углу title bar;
- **Настройки…** в меню приложения или в палитре команд `⌘K`.

![Настройки](assets/12-settings-light.png)

## Внешний вид

Доступны три варианта:

- **Системная** — следовать оформлению macOS;
- **Светлая**;
- **Тёмная**.

Настройка применяется к главному окну и окну настроек. Sidebar остаётся тёмным, чтобы сохранять контраст и стиль приложения.

## Сканирование

В настройках показано, что **повторный анализ не запускается**, пока идёт сканирование. Это не переключатель, а постоянная защита:

- новые запросы `scan` игнорируются на уровне модели;
- команды меню сканирования отключены;
- в палитре команд остаётся только «Остановить сканирование»;
- выбор новой папки во время скана не открывает панель.

Остановить текущий скан можно кнопкой **«Остановить»** на экране сканирования.

## Подтверждение перед Корзиной

По умолчанию DiskScope спрашивает подтверждение перед перемещением объектов в Корзину. Можно выбрать:

- **Спрашивать** — показывать диалог;
- **Без подтверждения** — сразу перемещать выбранное в Корзину.

Даже без подтверждения объекты попадают в Корзину и могут быть восстановлены. Настройка не отключает саму возможность удаления.

## Проверка обновлений

В разделе **«Обновления»** есть кнопка **«Проверить»**.

1. Нажмите **«Проверить»**.
2. DiskScope запрашивает последний стабильный релиз через GitHub Releases API.
3. Если версия актуальна, показывается «Установлена последняя версия».
4. Если доступна новая — её номер и кнопка **«Скачать»**.
5. «Скачать» открывает DMG из релиза; после загрузки закройте приложение, замените его в «Программах» и запустите снова.

Состояния:

| Состояние | Что показывает |
| --- | --- |
| Ожидание | «Проверка обновлений» и кнопка «Проверить» |
| Проверка | Индикатор и «Проверяем обновления…» |
| Актуально | «Установлена последняя версия» |
| Доступно | «Доступна версия X» и кнопка «Скачать» |
| Ошибка | «Не удалось проверить» и кнопка «Повторить» |

Проверка выполняется **только вручную**. Приложение не проверяет обновления при запуске и не устанавливает их автоматически.

### Что уходит в сеть

Только GET-запрос к:

`https://api.github.com/repos/fso13/DiskScope/releases/latest`

В заголовке User-Agent передаётся версия приложения, например `DiskScope/1.1.1`. Файлы, имена, пути и результаты сканирования не отправляются. GitHub может записывать IP-адрес и стандартные данные HTTP-запроса.

## О программе

В настройках видны:

- версия;
- номер сборки;
- версия macOS;
- архитектура (Apple Silicon или Intel);
- ссылки на документацию и GitHub.

Там же есть кнопка **«Сбросить настройки»**: тема возвращается к системной, подтверждение Корзины включается.

## Что хранится

- выбранная тема;
- настройка подтверждения Корзины;
- последняя папка сканирования;
- стандартные настройки macOS.

DiskScope не создаёт аккаунтов, облачных профилей и телеметрии.

## Если проверка не работает

- проверьте интернет;
- GitHub API может быть временно недоступен или ограничен по частоте запросов;
- если релизов ещё нет, GitHub вернёт ошибку — это нормально до публикации первого релиза;
- повторите позже.

См. [Решение проблем](Troubleshooting) и [Приватность и безопасность](Privacy-and-Security).
