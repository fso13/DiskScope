# Медиа-поиск

Вкладка **«Медиа»** (`⌘4`) появляется после первого сканирования. Она ищет файлы по типам в отдельных папках и не зависит от текущего дерева скана.

![Медиа-поиск](assets/10-media-light.png)

## Как работает

1. Откройте вкладку **«Медиа»**.
2. Добавьте одну или несколько папок для поиска. Если список пуст, подставляется текущая папка скана.
3. Отметьте типы файлов.
4. Нажмите **«Найти файлы»**.
5. Отметьте результаты чекбоксами или кнопкой **«Выбрать все»**.
6. Выберите папку назначения и нажмите **«Перенести»**.

Поиск можно отменить. Он выполняется в фоне и не блокирует интерфейс.

## Типы файлов

| Тип | Что ищет |
| --- | --- |
| **Изображения** | JPG, JPEG, PNG, HEIC, HEIF, TIFF, GIF, BMP, WebP, RAW и другие растровые форматы |
| **Музыка** | MP3, M4A, AAC, FLAC, WAV, AIFF, OGG, ALAC и другие аудиоформаты |
| **Видео** | MP4, MOV, MKV, AVI, M4V, WebM, MPEG и другие видеоформаты |
| **Документы** | PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX, RTF, ODT, EPUB, TXT, CSV, TSV |
| **DOC / DOCX** | Только документы Word |
| **PDF** | Только PDF |

Скрытые файлы, содержимое пакетов и симлинки пропускаются, чтобы не раздувать результаты и не показывать служебные данные.

## Результаты

В таблице показываются имя, папка, тип, размер и дата изменения. Можно:

- фильтровать по имени;
- выбирать отдельные файлы;
- выбрать все;
- снять выбор;
- сортировать по столбцам.

Показывается не больше **25 000** результатов. Если файлов больше, уточните папки или типы.

## Перенос в папку

1. Выберите файлы.
2. Укажите папку назначения.
3. Нажмите **«Перенести»**.

Если файл с таким именем уже есть, DiskScope добавляет суффикс ` 2`, ` 3` и так далее. Исходный файл перемещается, а не копируется.

Некоторые системные ограничения:

- нельзя переместить файл в ту же папку;
- при ошибке одного файла остальные продолжают переноситься;
- результат показывает количество успешных переносов и ошибок.

## Импорт в «Фото»

Для изображений доступна кнопка **«В Фото»**:

1. Выберите изображения.
2. Нажмите **«В Фото»**.
3. Подтвердите импорт.
4. Разрешите DiskScope доступ к «Фото», если macOS попросит.

Импортируются растровые форматы. **PSD, AI и SVG** остаются в папке, потому что PhotoKit не импортирует их как изображения.

> **Важно.** При импорте оригиналы перемещаются в медиатеку. Проверьте выбор перед подтверждением: операция меняет файлы на диске. Если оригинал не удалось переместить, DiskScope попробует отправить его в Корзину.

Разрешение: **Системные настройки → Конфиденциальность и безопасность → Фото**.

## Приватность

Поиск и перенос выполняются локально. Содержимое и имена файлов не отправляются в сеть. Сеть используется только для проверки обновлений в настройках.

## Ограничения

- Поиск не читает содержимое файлов и не индексирует метаданные EXIF.
- Скрытые файлы и пакеты не показываются.
- Жёсткие ссылки могут появляться по нескольким путям.
- Лимит результатов — 25 000.
- Поиск дубликатов не выполняется.
