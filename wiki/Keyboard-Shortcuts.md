# Горячие клавиши

## Основные

| Действие | Клавиши |
| --- | --- |
| Выбрать папку | `⌘O` |
| Сканировать домашнюю папку | `⇧⌘H` |
| Сканировать снова | `⌘R` |
| Наверх | `⌘↑` |
| Показать в Finder | `⇧⌘R` |
| Переместить в Корзину | `⌘⌫` |
| Карта | `⌘1` |
| Крупнейшие объекты | `⌘2` |
| Типы файлов | `⌘3` |
| Медиа-поиск | `⌘4` |
| Палитра команд | `⌘K` |
| Настройки | `⌘,` |

## Палитра команд

`⌘K` открывает палитру. В ней доступны:

- сканировать домашнюю папку;
- выбрать папку;
- сканировать снова;
- остановить сканирование;
- карта, крупнейшие, типы, медиа;
- показать в Finder;
- переместить в Корзину;
- настройки;
- полный доступ к диску;
- о программе.

Пока идёт сканирование, команды запуска нового скана скрыты — остаётся только остановка.

## Во время сканирования

- `⌘R`, `⇧⌘H`, `⌘O` не запускают новый скан;
- кнопки сканирования в меню отключены;
- остановить скан можно кнопкой **«Остановить»** или командой в палитре.

## Таблица

- `⌘` — добавить объект к выделению;
- `⇧` — выделить диапазон;
- двойной клик — открыть папку или показать файл в Finder;
- контекстное меню — открыть, показать в Finder, сканировать папку, переместить в Корзину.

## Настройки

`⌘,` работает из любого места приложения. Настройки также открываются шестерёнкой в title bar и пунктом меню.
