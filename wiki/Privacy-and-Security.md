# Приватность и безопасность

DiskScope создан как локальный инструмент. Он не требует аккаунта, не отправляет телеметрию и не использует сторонние библиотеки.

## Что остаётся на Mac

- имена файлов и папок;
- размеры и метаданные;
- результаты сканирования;
- тепловая карта;
- выбранная папка;
- настройки приложения;
- медиафайлы и результаты их переноса.

Всё это обрабатывается локально.

## Сеть

Единственный сетевой запрос — **проверка обновлений по кнопке** в настройках.

| Параметр | Значение |
| --- | --- |
| Адрес | `https://api.github.com/repos/fso13/DiskScope/releases/latest` |
| Метод | `GET` |
| Заголовки | `Accept`, `X-GitHub-Api-Version`, `User-Agent: DiskScope/<version>` |
| Что отправляется | Только стандартный HTTP-запрос; без файлов, имён и путей |
| Когда | Только после нажатия «Проверить» |

GitHub может сохранять IP-адрес и стандартные данные запроса в своих логах. Политика GitHub описана на github.com.

Приложение **не проверяет обновления автоматически** и **не устанавливает их без вашего действия**.

## Что хранится в UserDefaults

- последняя папка сканирования (`lastScanPath`);
- выбранная тема;
- настройка подтверждения Корзины.

DiskScope не создаёт облачных профилей, аккаунтов и аналитики.

## Доступ к файлам

- Приложение читает метаданные файлов.
- Для медиа-поиска читаются имена и расширения; содержимое не индексируется.
- При импорте в «Фото» читаются выбранные изображения и создаются объекты PhotoKit.
- Для защищённых папок требуется **«Полный доступ к диску»**.
- Для импорта в «Фото» требуется разрешение PhotoKit.

## Перемещение и удаление

- Объекты перемещаются в Корзину, выбранную папку или «Фото» только по действию пользователя.
- По умолчанию перед Корзиной показывается подтверждение.
- Подтверждение можно отключить в настройках; объекты всё равно попадают в Корзину и могут быть восстановлены.
- При импорте в «Фото» оригиналы перемещаются в медиатеку.

## Подпись и Gatekeeper

DiskScope подписан **ad-hoc** и не нотаризован Apple. Поэтому Gatekeeper может попросить открыть приложение через контекстное меню → **«Открыть»**.

Это не признак вредоносного кода, а ограничение локальной сборки без Developer ID. Для публичного распространения нужна нотаризация.

## Сторонние зависимости

Проект использует только Apple frameworks: SwiftUI, AppKit, Foundation, PhotoKit и системные API. В `Package.swift` нет внешних пакетов.

## Как проверить

- Исходный код доступен на [GitHub](https://github.com/fso13/DiskScope).
- Сетевой запрос можно проверить в мониторе соединений (Little Snitch, LuLu, `nettop`).
- Все обращения к сети идут только после нажатия «Проверить».

## Сообщить о проблеме безопасности

Не публикуйте чувствительные данные в открытых issue. Используйте приватный security advisory в GitHub, если он доступен для репозитория, или свяжитесь с владельцем репозитория.
