# Решение проблем

## Быстрая таблица

| Симптом | Вероятная причина | Что делать |
| --- | --- | --- |
| «Не удаётся открыть приложение» | Gatekeeper и ad-hoc подпись | Контекстное меню → «Открыть» |
| Мало данных в `~/Library` | Нет «Полного доступа к диску» | Выдать разрешение и перезапустить |
| Скан идёт долго | Большой том или миллионы файлов | Дождаться, остановить или выбрать папку уже |
| Не находится медиа | Неверные папки/типы или лимит | Проверить источники, типы и 25 000 результатов |
| «В Фото» не работает | Нет доступа к «Фото» или формат не поддерживается | Разрешить PhotoKit; PSD/AI/SVG не импортируются |
| Проверка обновлений не работает | Нет сети или GitHub API недоступен | Проверить интернет и повторить |
| Размер отличается от Finder | allocated size vs logical size | Это ожидаемо; см. ниже |
| DMG без фона | Finder не применил `.DS_Store` | Открыть образ заново или пересобрать DMG |

## Приложение не открывается

1. Найдите `DiskScope.app` в Finder.
2. Control-клик → **«Открыть»**.
3. Подтвердите.

Если не помогает:

- **Системные настройки → Конфиденциальность и безопасность** → **«Всё равно открыть»**;
- проверьте, что приложение не повреждено при скачивании;
- скачайте DMG заново.

DiskScope подписан ad-hoc и не нотаризован. Это ожидаемо.

## Нет доступа к защищённым папкам

1. Переместите приложение в «Программы».
2. **Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску**.
3. Добавьте `DiskScope.app`.
4. Перезапустите приложение.

Разрешение привязано к пути: если переместить приложение после выдачи, его нужно выдать заново.

## Скан идёт слишком долго

- Большой том и миллионы файлов могут сканироваться минуты.
- Выберите конкретную папку вместо всего диска.
- Остановите скан кнопкой **«Остановить»**.
- Проверьте, не открыт ли сетевой/внешний том.

Повторный анализ во время скана не запускается — это нормально.

## Медиа-поиск ничего не находит

- Проверьте, что добавлены нужные папки.
- Отметьте типы файлов.
- Скрытые файлы, пакеты и симлинки пропускаются.
- Если результатов больше 25 000, уточните папки или типы.
- Поиск не читает содержимое файлов.

## «В Фото» не импортирует

- Разрешите доступ: **Системные настройки → Конфиденциальность и безопасность → Фото**.
- PSD, AI и SVG не импортируются PhotoKit.
- Проверьте, что выбраны изображения поддерживаемого растрового формата.
- Оригиналы перемещаются; убедитесь, что это ожидаемое поведение.

## Проверка обновлений не работает

- Проверьте интернет.
- GitHub API может вернуть ошибку при отсутствии релизов или лимите запросов.
- Нажмите **«Повторить»**.
- Проверка работает только по кнопке; автоматических запросов нет.

## Размеры отличаются от Finder

DiskScope показывает **allocated size** — место, которое файл занимает на диске. Finder может показывать логический размер. Архивы, разреженные файлы, сжатые и клонированные данные могут отличаться.

## DMG выглядит как обычная папка

Кастомное оформление хранится в `.DS_Store`. Если Finder не применил настройки:

- закройте и откройте образ заново;
- проверьте, что том смонтирован как `DiskScope`;
- пересоберите DMG через `./build.sh`.

## Как сообщить об ошибке

Создайте [issue](https://github.com/fso13/DiskScope/issues) и укажите:

- версию DiskScope (настройки → О программе);
- версию macOS;
- архитектуру;
- шаги воспроизведения;
- ожидаемое и фактическое поведение;
- скриншот, если он не содержит личных данных.

Не прикладывайте содержимое домашних папок и другие чувствительные данные.

## Сброс настроек

В настройках есть **«Сбросить настройки»**. Это вернёт системную тему и включит подтверждение Корзины. Настройки хранятся в UserDefaults.
