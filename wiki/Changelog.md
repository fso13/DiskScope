# Changelog

Полная история — в [CHANGELOG.md](https://github.com/fso13/DiskScope/blob/main/CHANGELOG.md).

## 1.1.1 — 2026-10-20

### Добавлено

- Настройки приложения (`⌘,`): тема, подтверждение Корзины, проверка обновлений, сведения и ссылки.
- Шестерёнка в title bar и пункт «Настройки…» в палитре команд.
- Проверка обновлений через GitHub Releases: ручная, с состояниями и прямой ссылкой на DMG.
- Кастомный DMG-лаунчер: фон, стрелка, позиции `DiskScope.app` и `Applications`, скрытые панели Finder.
- Кастомный title bar в духе VS Code: traffic lights, бренд, статус и палитра `⌘K`.
- Пайплайн релиза создаёт GitHub Release через `gh release create` с описанием и прямыми ссылками.

### Исправлено

- Сборка на Xcode 16.4: snapshot entry point и сборка только продукта `DiskScope`.
- DMG использует корректный Finder layout и фирменный фон.
- Повторный анализ во время сканирования блокируется на уровне модели, меню и палитры.

### Тесты

- 42 XCTest, включая медиа, переносы, модель, защиту от повторного скана и сравнение версий.

## 1.1.0 — 2026-10-20

### Добавлено

- Вкладка «Медиа» (`⌘4`): поиск изображений, музыки, видео и документов по папкам.
- Выбор результатов, перенос в папку с разрешением конфликтов имён.
- Импорт изображений в «Фото» с перемещением оригиналов.
- Usage descriptions и обработка отказа доступа.
- 40 XCTest для медиа, переносов и модели.

## 1.0.0 — 2026-10-20

### Добавлено

- Нативное приложение DiskScope для macOS 14+.
- Быстрый сканер `getattrlistbulk` + `openat`.
- Тепловая карта, крупнейшие объекты, типы файлов.
- Очистка через Finder и Корзину с обновлением дерева.
- Пакеты, симлинки и точки монтирования.
- Русский интерфейс, светлая и тёмная темы.
- 23 XCTest.
- CLI, snapshot-рендер, GitHub Actions и сайт документации.
