# Возможности

DiskScope — не просто сканер размера папок. Это инструмент, который помогает понять структуру диска и безопасно освободить место.

## Обзор

| Возможность | Описание |
| --- | --- |
| **Быстрый сканер** | `getattrlistbulk` + `openat`, запасной `readdir + fstatat`; прогресс и отмена |
| **Тепловая карта** | Двухуровневая squarified-карта с навигацией и подсказками |
| **Крупнейшие объекты** | Файлы и приложения по размеру; пакеты `.app` — одним объектом |
| **Типы файлов** | Видео, изображения, музыка, архивы, документы, код, другое |
| **Медиа-поиск** | Изображения, музыка, видео, документы, DOC/DOCX, PDF по папкам |
| **Очистка** | Finder и Корзина с подтверждением; мгновенное обновление дерева |
| **Кастомное окно** | Traffic lights, бренд, статус и палитра команд `⌘K` |
| **Настройки** | Тема, подтверждение Корзины, обновления, сведения |
| **Локальность** | Нет телеметрии; сеть только для проверки обновлений по кнопке |
| **Universal** | Apple Silicon и Intel, macOS 14+ |

## Сканер

DiskScope читает метаданные файлов, а не содержимое. Основной путь — `getattrlistbulk` с `openat`: меньше системных вызовов и высокая скорость на больших каталогах. Если bulk-API недоступен, используется `readdir + fstatat`.

Во время сканирования видны:

- текущий путь;
- количество файлов и папок;
- объём;
- прошедшее время.

Скан можно отменить. Пока он идёт, повторный анализ не запускается.

## Тепловая карта

Карта строится алгоритмом squarified treemap. Площадь прямоугольника пропорциональна размеру объекта. Для крупных папок показывается второй уровень вложенности и полоса с именем родителя.

- клик открывает папку;
- наведение показывает имя, размер и долю;
- хлебные крошки показывают путь;
- двойной клик в таблице открывает папку или Finder.

## Крупнейшие объекты

Список отсортирован по размеру. Приложения `.app` считаются одним объектом: внутренние файлы не участвуют в рейтинге и не предлагаются к удалению по отдельности.

## Типы файлов

Категории: видео, изображения, музыка, архивы, документы, код и другое. По каждой категории можно перейти к крупнейшим файлам.

## Медиа-поиск

Вкладка **«Медиа»** (`⌘4`) ищет файлы по типам в отдельных папках, не зависимо от текущего скана. Найденное можно перенести в выбранную папку или импортировать изображения в «Фото».

Подробнее — [Медиа-поиск](Media-Search).

## Очистка

- **Показать в Finder** (`⇧⌘R`) — открыть выбранное или текущую папку.
- **Переместить в Корзину** (`⌘⌫`) — с подтверждением; объекты можно восстановить.
- После удаления дерево и суммы обновляются сразу, без полного перескана.

Подтверждение можно отключить в настройках, но по умолчанию оно включено.

## Окно и навигация

Кастомный title bar с нативными traffic lights, брендом и статусом. Командная палитра `⌘K` открывает быстрые действия: скан, переходы, Finder, Корзина, настройки.

Окно можно тянуть за заголовок; двойной клик по заголовку зумит окно.

## Настройки и обновления

`⌘,` открывает настройки:

- системная, светлая или тёмная тема;
- подтверждение перед Корзиной;
- проверка обновлений через GitHub Releases;
- версия, сборка, система и архитектура;
- документация, GitHub и сброс.

Подробнее — [Настройки и обновления](Settings-and-Updates).

## Приватность

DiskScope не отправляет файлы, имена и результаты сканирования. Сеть используется только для проверки обновлений по кнопке. Подробнее — [Приватность и безопасность](Privacy-and-Security).

## Ограничения

- Жёсткие ссылки считаются по каждому пути.
- Снимки APFS и purgeable-пространство не показываются отдельно.
- Файлы меньше 64 КБ агрегируются по папкам.
- Поиска дубликатов нет.
- Медиа-поиск показывает не больше 25 000 результатов.

См. [Архитектура](Architecture) и [FAQ](FAQ).
