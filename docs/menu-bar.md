# Меню-бар

Монитор свободного места — необязательная иконка в строке меню.

## Включение

**Настройки (`⌘,`) → Меню-бар → «Показывать свободное место»**.

- **Свободно** — заголовок вида `95,1 GB`.
- **Процент** — доля свободного места, например `25%`.

Иконка обновляется раз в минуту и при открытии меню.

## Меню

Клик по иконке показывает:

- свободно / занято и процент;
- purgeable, если он известен;
- **Открыть DiskScope**;
- **Сканировать домашнюю папку**;
- **Обновить**;
- **Настройки…**;
- **Выйти**.

Пока монитор включён, закрытие окна не завершает приложение: иконка остаётся в
строке меню. Клик по иконке в Dock или повторный запуск возвращает окно.

## Доступность

Заголовок иконки имеет VoiceOver-метку вида «DiskScope, 95,1 GB, 95,1 GB
free». Пункты меню — обычные `NSMenuItem`, доступные с клавиатуры.

## Ограничения

- Монитор работает, пока запущено приложение; автозапуск при входе в систему
  не включён.
- Purgeable показывается, только если macOS вернула эту оценку.
- Приложение не опрашивает диск чаще раза в минуту, чтобы не мешать работе.
