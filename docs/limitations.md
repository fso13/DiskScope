# Ограничения и приватность

## Что важно знать

| Ограничение | Причина |
| --- | --- |
| Жёсткие ссылки считаются по каждому пути | Сканер, как и большинство анализаторов, не дедуплицирует inode-ы. `du` делает это иначе, поэтому суммы могут отличаться. |
| Снимки APFS и purgeable-пространство не показываются отдельно | Они не представлены обычными файлами в пространстве имён; свободное место берётся из `statfs`. |
| Клоны APFS считаются как обычные файлы | Занятый размер каждого клона учитывается полностью. |
| Файлы меньше 64 КБ не видны по отдельности | Они собраны в строку «Мелкие файлы» внутри папки. Суммы точные, детализация — нет. |
| Пакеты `.app` — один объект в рейтингах | Иначе сотни фреймворков и ресурсов засоряли бы «Крупнейшие» и могли быть удалены по отдельности. |
| Нет поиска дубликатов | Это возможное следующее расширение; сейчас приоритет — карта и крупнейшие объекты. |
| Интерфейс на русском | Локализация пока одна. |
| Подпись ad-hoc, без нотаризации | Для локальной сборки этого достаточно; для распространения нужен Developer ID. |

## Почему размеры иногда отличаются от Finder

DiskScope показывает **allocated size** — сколько места файл реально занимает
на диске. Finder в инспекторе может показывать логический размер. Для
разреженных файлов, архивов, клонов APFS и жёстких ссылок эти числа
расходятся. Для сравнения с `du` используйте allocated size — он совпадает.

## Почему нужен «Полный доступ к диску»

macOS TCC скрывает содержимое защищённых каталогов: почты, сообщений,
фототеки, домашних папок других пользователей. Без разрешения сканирование
продолжается, но эти объекты пропускаются, а в интерфейсе появляется баннер с
их количеством.

Порядок выдачи разрешения — в разделе [Как пользоваться](usage.md).

## Приватность и безопасность

- Приложение не содержит сетевого кода и не отправляет телеметрию.
- Оно читает только метаданные файлов (имена, размеры, типы).
- Единственные записи: настройка последней папки в `UserDefaults` и
  перемещение выбранных объектов в Корзину по явному подтверждению.
- Нет фоновых демонов, автозапуска и повышенных привилегий.
