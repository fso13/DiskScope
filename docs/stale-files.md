# Заброшенные файлы

Раздел «Очистка» находит крупные файлы, которые давно не изменялись.

## Критерии

- Файл (не папка и не пакет), размер не меньше **10 МБ**.
- Дата изменения старше выбранного срока: **6, 12, 24 или 36 месяцев**.
- Исключены системные пути (`/System`, `/Library`, `/usr`, `/bin`, `/private`,
  `/Applications` и т.п.).
- Исключены `.git`, `node_modules`, `Pods`, `.build`, `DerivedData`, `Carthage`,
  `.venv`, `target`, `.idea`, `.next` и библиотечные расширения (`framework`,
  `dylib`, `a`, `o`, `swiftmodule`, `xcframework`).
- Файлы внутри пакетов `.app` и символических ссылок не предлагаются.

## UI

В «Очистке» есть секция **«Заброшенные файлы»**:

- общий потенциал и количество найденных файлов;
- топ-20 по размеру;
- переключатель срока (6/12/24/36 месяцев);
- чекбоксы, **«Выбрать топ-20»**, удаление через общую кнопку «Очистить…»
  с подтверждением и `⌘Z` для Корзины.

## Глобальный поиск

В фильтре даты появились варианты **«Старше 6/12/24 месяцев»**. Они
комбинируются с размером, категорией, типом и сортировкой.

## Дата доступа

Используется дата **изменения** (`mtime`). `ATTR_CMN_ACCTIME` не используется:
macOS может обновлять дату доступа при чтении, отключать её или не обновлять
годами, поэтому она ненадёжна для рекомендаций по очистке. Для проверки
«последнего использования» лучше ориентироваться на mtime и содержимое папки.

## Ограничения

- Размер — выделенные блоки, как в остальном DiskScope.
- Топ-20 ограничен; полный список доступен через глобальный поиск.
- Срок считается как 30 дней на месяц.
- Скрытые файлы не исключаются автоматически, кроме перечисленных папок.
