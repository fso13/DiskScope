# Roadmap

**Цикл:** 3.0 · **Релиз:** 2.0.0 · **Обновлено:** 23 октября 2026

**Задачи:** [issues](https://github.com/fso13/DiskScope/issues) · **Этапы:** [milestones](https://github.com/fso13/DiskScope/milestones) · **Новые:** [#57–#72](https://github.com/fso13/DiskScope/issues?q=is%3Aissue+is%3Aopen)

Цикл 1.2–2.0 закрыт: DiskScope сканирует, объясняет место, чистит, ищет
дубликаты, публикуется и встроен в macOS. Следующий цикл — не «добавить ещё
кнопок», а сделать цифры **доказуемо правильными**, действия — **предсказуемыми**,
а приложение — **дешёвым в поддержке**.

Новый план состоит из двух параллельных треков: **фичи** (3.0–3.2) и
**техдолг** (T1–T7). Техдолг не «потом»: 25–30% каждого релиза — это T-задачи,
иначе фичи продолжат уплотнять `AppModel` и сканер.

## Принципы

1. **Локально.** Данные не покидают Mac; сеть — только обновления.
2. **Безопасно.** Удаление только после подтверждения; всё обратимо через ⌘Z.
3. **Доказуемо.** Числа совпадают с `du`/`df` там, где это возможно; расхождения
   объяснены в UI, а не спрятаны.
4. **Быстро.** Скан не блокирует UI; кэш и параллельность не ломают суммы.
5. **Маленькие шаги.** Один issue — один проверяемый сценарий.

## Трек фич

### 3.0 — «Очистка с гарантией»

**Цель.** Пользователь видит не «сколько занято», а «что освободится, если
удалить вот это» — с учётом hard links, клонов, снимков и бюджета.

**Сценарий.** «Хочу 20 ГБ» → планировщик собирает правила, старые файлы,
бюджеты и дубликаты → показывает прогноз, риск и что произойдёт → удаляет
пачкой → `df` подтверждает результат.

## Метрики

- **Точность reclaim:** прогноз vs `df` ≤10% на фикстуре; ложных «освободится»
  для клонов/снимков — 0.
- **Кэш:** повторный скан без изменений <1 с; cold home scan — benchmark.
- **Надёжность:** 0 потерь данных; 100% удалений отменяемы; 0 flaky за 50 прогонов.
- **Покрытие:** Core ≥85%, UI smoke на 6 экранов.
- **Доступность:** 100% интерактивных элементов с VO-меткой; Dynamic Type.
- **Локализация:** 100% ключей и docs на EN/RU.
- **CI:** release smoke на каждом теге; Dependency review зелёный.

## Вне планов

- Облако, аккаунты, синхронизация, телеметрия.
- Автоудаление без подтверждения.
- Windows/Linux.
- App Store и песочница: конфликтует с полным сканом.
- Полный учёт APFS-клонов без стабильного публичного extent API.
